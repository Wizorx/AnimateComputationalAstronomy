Podemos computar os coeficientes utilizando:

$ = _{i = 1}^{n}2.x_i.(ax_i + b - y_i) = 0$

$ = _{i = 1}^{n}2.(ax_i + b - y_i) = 0$

\(\therefore\)

\(a = \frac{\sum_{i = 1}^{n} x_i (y_i - \bar{y})}{\sum_{i = 1}^{n} x_i (x_i - \bar{x})}\)

\(b = \bar{y} - a\bar{x}\)

onde

\(\bar{x} = \frac{1}{N}\sum_{i = 1}^{n} x_i\)

\(\bar{y} = \frac{1}{N}\sum_{i = 1}^{n} y_i\)

a = np.sum(x*(y - y.mean())) / np.sum(x*(x - x.mean()))
print('Coeficiente Angular: ', a)
Coeficiente Angular:  0.3093444729928444
b = y.mean() - a*x.mean()
print('Coeficiente linear: ', b)
Coeficiente linear:  17.56814695035778
# Visualizando nosso resultado

pl.plot(x, y, 'k.-')
pl.plot(x, a*x + b, 'r-')
pl.show()

Esse foi um exemplo de um ajuste por mínimos quadrados para o caso de um ajuste simples que pode ser resolvido algebricamente. Mas como fazer de forma numérica?

12.0.1 Vamos fazer um Monte Carlo

# Primeiro, definir o nosso problema

def reta(x, a, b):
    return a*x + b
# Definimos alguns chutes iniciais 

pl.plot(x, y, 'k.-')
pl.plot(x, reta(x, 0.5, 10), 'r-')
pl.show()
# Vamos criar valores randômicos para testar
param_a = np.random.uniform(0, 1, 100000)
param_b = np.random.uniform(0, 30, 100000)
# Como estamos preenchendo o espaço de parâmetros?

pl.plot(param_a, param_b, 'k.')
pl.xlabel('a', fontsize=15)
pl.ylabel('b', fontsize=15)
pl.show()

# Cada ponto preto é uma simulação que vamos fazer de forma iterativa

pl.plot(param_a[0], param_b[0], 'r.')

Computando um modelo e calculando o valor de:

\(S = \sum_{i = 1}^{N} (y_i - f(x_i))^2\)

y_model = reta(x, a=param_a[0], b=param_b[0])

S = np.sum((y - y_model)**2)
print('Soma dos quadrados dos Resíduos: ', S)

# Quanto maior o S, pior é o ajuste, vamos calcular S para todos os valores simulados
Soma dos quadrados dos Resíduos:  18760.743305494314
S = np.array([])

for i in range(len(param_a)):
    y_model = reta(x, a=param_a[i], b=param_b[i])
    S = np.append(S, np.sum((y - y_model)**2))
print('Valor mínimo da soma dos quadrados dos resíduos: ', S.min())
