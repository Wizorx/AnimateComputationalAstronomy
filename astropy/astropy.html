6.1 1) Visão Geral

Detalhes sobre o pacote Astropy podem ser encontrados em www.astropy.org

Data structures and transformations

  • Constants (astropy.constants)
  • Units and Quantities (astropy.units)
  • N-Dimensional Datasets (astropy.nddata)
  • Data Tables (astropy.table)
  • Time and Dates (astropy.time)
  • Time Series (astropy.timeseries)
  • Astronomical Coordinate Systems (astropy.coordinates)
  • World Coordinate System (astropy.wcs)
  • Models and Fitting (astropy.modeling)
  • Uncertainties and Distributions (astropy.uncertainty)

Files, I/O, and Communication

  • Unified File Read/Write Interface
  • FITS File Handling (astropy.io.fits)
  • ASCII Tables (astropy.io.ascii)

Computations and utilities

  • Cosmological Calculations (astropy.cosmology)
  • Convolution and Filtering (astropy.convolution)
  • IERS data access (astropy.utils.iers)
  • Data Visualization (astropy.visualization)

6.4 4) Astropy Time

Lidando com o tempo!

from astropy.time import Time
t = Time.now()
print(t)
2026-08-12 23:04:29.495200
t.scale
'utc'
# agora podemos acessar esse tempo de diferentes formas
t.iso
'2026-08-12 23:04:29.495'
#Data Juliana
t.jd
np.float64(2461265.4614524907)
# Data Juliana modificada
t.mjd
np.float64(61264.96145249074)
# Besselian Epoch
t.byear
np.float64(2026.6150189842094)
# Além disso, o tempo tem uma escala associada
t.scale
'utc'

Segue a lista de escalas de tempo

  • tai -> International Atomic Time
  • tcb -> Barycentric Coordinate Time
  • tcg -> Geocentric Coordinate Time
  • tdb -> Barycentric Dynamical Time
  • tt -> Terrestrial Time
  • ut1 -> Universal Time
  • utc -> Coordinate Universal Time
  • local -> Local Time Scale
# e podemos converter entre escalas de tempo
t.tdb.iso
'2026-08-12 23:05:38.678'
t.tt.iso
'2026-08-12 23:05:38.679'
t.utc.iso
'2026-08-12 23:04:29.495'

Cada escala de tempo tem diferentes aplicações na astronomia

# Além disso, podemos combinar o Time com o units de maneira automática
